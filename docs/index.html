Forge in 30 seconds

Most systems already know how to execute.
They need a better way to decide what to execute.

Forge sits between the state you have and the state you want. It calculates a transition that is explicit enough to inspect, validate, persist, approve, explain or hand to your own orchestration layer.

01

Describe state

Use your own CLR types, identities, states and domain semantics. Forge does not require a runtime metadata model.

02

Calculate the transition

Generate Deltas, reconciliation plans, dependency waves, constraints, manifests and typed planning results.

03

Execute your way

Persist, publish, call, schedule or approve with infrastructure you already own. Forge stops before side effects begin.

THE BOUNDARY

Forge owns planning—not your application.

That boundary is deliberate. Plans stay testable and deterministic while business policy, authorization, persistence and transport remain where they belong.

Three core packages, one design language

Start at the smallest useful primitive.

Forge is a family, but you do not need the whole family for every problem.

ΔFORGE.DELTA

What changed inside this object?

Source-generated semantic comparison with typed property changes, nested deltas, collection semantics, merge analysis and inversion.

[GenerateDelta]
public sealed record Customer(...);

var delta = CustomerDelta.Between(before, after);
Forge.Delta on NuGet →
⇄FORGE.SYNC

How does current state become desired state?

Keyed reconciliation plus typed planning: Add / Update / Remove / Preserve, nested and cross-type sync, dependencies, manifests, topology and replanning.

[GenerateSync(nameof(OrderItem.Id))]
public sealed record OrderItem(...);

var plan = OrderItemSync.Plan(current, desired);

Forge + AI coding agents

Give the agent a typed planning surface.
Keep authority outside the model.

Forge can make change-oriented code easier for an agent to reason about because the transition is explicit and testable. The agent can inspect a plan, its dependencies and its preconditions without Forge granting it permission to execute anything.
