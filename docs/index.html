Family architecture

Related tools, not one giant framework.

The shared design language is deliberate; the dependency graph stays small.

CORE RELATIONSHIP

Sync builds on Delta.

When a keyed item is updated, Sync can carry its typed semantic Delta. That relationship is useful and explicit.

Forge.Sync→Forge.Delta
INDEPENDENT CORE

Parse stands on its own.

Parse is a test-oriented structured matching engine. It does not require Delta or Sync and does not inherit their planning model.

Forge.Parse→System.Text.Json
OPTIONAL ADAPTER

Reqnroll stays thin.

The adapter translates DataTables into Parse expectations. The matching rules remain in Forge.Parse.

Forge.Parse.Reqnroll→Forge.Parse

Where the family fits

Different problems. Consistent engineering values.

Semantic updates

Know exactly which participating properties changed and preserve domain-specific equality.

⇄

{ }

Integration tests

BDD tables

⌘
