# Forge 1.14 review — executed-work-aware replanning

## Capability

Forge can replan desired work around a typed execution snapshot without pretending already-started work is freely replaceable.

## Safety model

- Equivalent pending work retains its operation identity.
- Equivalent running/completed work is preserved as locked work.
- Pending changed/removed work can be replaced or cancelled before start.
- Completed changed/removed work is surfaced as compensation-required.
- Running changed/removed work is surfaced as a conflict requiring application policy.

## SOLID

Application state interpretation is isolated behind `IExecutionStateClassifier<TState>`. Result categories are separate record types, avoiding invalid enum/null combinations.

## Complexity

Replanning indexes desired operations once and is O(n) average with hash-based logical identity.
