# Forge 1.5 review — Impact analysis

## Capability

Forge can now propagate a change through an explicit directed impact graph and return:

- directly affected logical items;
- transitively affected logical items;
- one deterministic shortest explanation path to every affected item;
- the application-owned reason carried by each edge.

## Example

```text
subnet --framedIpv4--> ipvpn --service-state--> internet
```

Changing `subnet` reports `ipvpn` as direct impact and `internet` as transitive impact, with the complete reason path preserved.

## Boundary

Forge does not infer propagation rules from domain relationships. The application supplies the graph edges that are semantically propagating. Cycles are safe because already-visited nodes are not revisited.

## Why this is a feature

Sync answers which state changed. Impact analysis answers which other logical state may need reevaluation because of that change. Those are different planning questions and are now separate composable primitives.
