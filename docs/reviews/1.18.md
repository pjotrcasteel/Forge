# Forge 1.18 review — scenario matrix simulation

## Capability

Forge can enumerate combinations of typed scenario axes and stream simulation results without materializing the full Cartesian product.

## Production properties

- Scenario and case identities are application types, not strings.
- Cartesian enumeration is lazy, avoiding an up-front O(n×m) allocation.
- Async evaluation passes `CancellationToken` to every scenario and checks cancellation before evaluation.
- Simulation behavior is supplied through focused evaluator interfaces; Forge performs no I/O itself.

## Complexity

Time is necessarily proportional to the scenarios actually enumerated. Working memory is O(1) beyond the supplied axes and evaluator state.
