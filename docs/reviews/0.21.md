# 0.21 review — typed operation planning

## Capability

A structural `SyncPlan` can now be classified into application-defined typed operations. Update classification receives the generated Delta, so operation selection can depend on what changed rather than merely whether something changed.

## Example

An updated item can become `Update` when ordinary state changed, but `Replace` when a particular identity-like or topology-sensitive property changed. Forge records the decision and executes nothing.

## Alignment

Operations are user-defined values. Forge contains no provisioning, persistence, messaging or cancellation policy.
