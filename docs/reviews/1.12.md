# Forge 1.12 review — typed provenance

## Capability

Applications can model why operations exist as a strongly typed cause/effect graph and trace shortest root-cause paths to any target.

## Design

- Applications own `TNode` and `TKey`; Forge has no string cause taxonomy.
- Graph creation validates identity and endpoint integrity before tracing.
- Result ordering follows input order for deterministic diagnostics.
- The graph is immutable after construction and contains no executable behavior.

## Complexity

Construction is O(V + E). A trace uses reverse breadth-first traversal O(V + E) for the reachable provenance subgraph.
