# 0.23 review — topology reconciliation

## Capability

Forge can now treat nodes and relationships as one topology transition. Both current and desired topology snapshots are validated for referential integrity before node and edge plans are produced.

## Production value

Real desired-state systems reconcile relationships as well as objects: networks, authorization graphs, workflows, infrastructure and service topologies. A collection-only view can delete a node while leaving an invalid edge or add an edge before its node exists.

## Structural application order

The topology plan exposes graph-safe phases: remove edges, remove nodes, add nodes, update nodes, update edges, add edges.

## Alignment

Forge understands only keys, endpoints and state equality. It has no knowledge of RFSs, resources, services or infrastructure providers.
