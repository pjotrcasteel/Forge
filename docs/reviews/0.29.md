# 0.29 review — canonical portable plan identity

## Capability

Portable Sync manifests now have a canonical SHA-256 digest. Canonicalization fixes manifest property order, object-property order, change-path order and operation order so JSON formatting or serialization ordering does not change the plan identity.

## Production value

Approval systems, audit records and deferred executors can bind an approval to the exact semantic portable plan they reviewed. `VerifySha256Hex` uses fixed-time comparison.

## Distinction from 0.25

0.25 semantic hashes are fast and equality-consistent inside one process. 0.29 manifest digests are cross-process portable plan identities suitable for persistence and approval boundaries.
