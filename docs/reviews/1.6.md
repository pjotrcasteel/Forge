# Forge 1.6 review — Plan constraints

## Capability

Plans can now be validated through composable typed constraints before execution. Validation returns every violation instead of throwing or failing at the first rule.

The generic `PlanConstraintSet<TPlan>` works with any planning type. `SyncPlanConstraintBuilder` adds common structural rules such as maximum change count, no removals and protected logical keys. Dependency plans have a convenience acyclic constraint.

## Boundary

Constraints are predicates supplied or selected by the application. Forge reports invalid plans; it still does not execute, authorize or approve them.

## Why this is a feature

A plan can now become a first-class assessment artifact: calculate first, validate the whole proposal, and only then let the application decide whether execution is permitted.
