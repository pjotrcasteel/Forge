# Forge 1.19 review — strongly typed plan templates

## Capability

Consumers can define reusable partial plan-template types. Forge generates the stable `Instantiate(context)` API while the application owns the typed `Build` implementation.

## Compile-time contract

`[GeneratePlanTemplate]` carries context, operation and key CLR types. Generated code exposes no string operation names, reflection lookup, or runtime plugin activation. Invalid non-partial templates receive a compile-time diagnostic.

## Runtime boundary

`PlanTemplateBuilder` validates duplicate operation keys and dependency endpoints, then builds deterministic dependency waves. The resulting template instance is immutable.

## Extensibility

Application templates can add arbitrary domain operations and conditional build logic without modifying Forge. Forge owns only construction mechanics and structural validation.
