# 0.20 review — dependency-aware reconciliation

## Capability

`DependencyPlanner` converts any keyed set with dependency references into deterministic execution waves. It exposes prerequisite-first creation waves, dependent-first deletion waves, and unresolved cycle keys.

## Production value

Desired-state reconciliation often identifies *what* must change but not a safe order. Provisioning, infrastructure, configuration and deletion workflows require dependency ordering and cycle detection before I/O starts.

## Semantics

Dependencies that point outside the supplied set are treated as already satisfied/external. Duplicate dependency declarations are collapsed. Independent operations preserve input order.

## Alignment

The planner is domain-neutral and executes nothing. It does not know about services, resources, databases or transports.
