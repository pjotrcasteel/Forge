# 0.25 review — semantic hashing

## Capability

Generated Delta types now expose `GetSemanticHashCode(value)`. Equivalent values under generated Delta semantics produce the same hash code, including custom comparers and nested generated state.

## Production value

This enables cheap in-process pre-indexing, state caches and change short-circuiting that follow Forge's semantic equality rather than raw CLR object identity.

## Deliberate limitation

The result is an in-process semantic hash, not a persisted fingerprint or ETag. .NET `IEqualityComparer<T>.GetHashCode` does not promise stable values across processes, runtimes or versions. Forge does not make a portability promise the comparer contract cannot uphold.
