# Forge 1.16 review — typed alternative plans

## Capability

Applications can represent multiple valid plans, evaluate them into their own metric type, and select using their own preference policy.

## Boundary

Forge deliberately has no built-in cost/risk/duration weighting. `IPlanEvaluator` calculates metrics and `IPlanPreference` defines ordering. Equal preferences remain visible as ties.

## Determinism and performance

Evaluation is one pass over alternatives. Selection is one pass plus a tie pass and retains input-order stability. No reflection or dynamic scoring is used.
