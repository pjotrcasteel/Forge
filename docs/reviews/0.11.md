# Milestone 0.11 review — external types

## Goal

Allow Delta to be useful when the compared model comes from another package, generated code or a layer that should not reference Forge attributes.

## What changed

`GenerateDeltaProfileAttribute` can now be placed on a local marker type:

```csharp
[GenerateDeltaProfile(typeof(ExternalCustomer))]
public sealed class ExternalCustomerProfile
{
}
```

Forge generates `ExternalCustomerProfileDelta`, including typed property changes, `AreEquivalent` and `Between`.

## Alignment review

This improves adoption without adding runtime reflection or configuration registries. Profiles remain compile-time configuration and generated code remains AOT/trimming friendly.

0.11 intentionally does not yet add per-property profile overrides. Ignore/comparer/normalization configuration belongs to the richer configuration milestone rather than being rushed into the first external-type API.

## Decision

Proceed. Collection equality is now the largest source of accidental false changes and needs explicit, reusable semantics.
