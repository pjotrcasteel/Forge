# 0.26 review — portable change manifests

## Capability

Delta and Sync plans can now be projected into versioned JSON-safe manifest documents. A manifest contains operation keys, current/desired JSON values and typed Delta property paths without serializing generated implementation types.

## Production value

Plans can cross the process boundary: audit logs, approval flows, outboxes, diagnostics, change previews and later replay systems can consume a stable data contract rather than the generator's runtime classes.

## Boundary

A manifest describes a transition; it is not an instruction to execute it. Deserializing a manifest does not mutate application state.
