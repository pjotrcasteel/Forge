# 0.30 review — cross-type parity

## Capability

Cross-type plans now support the same production lifecycle as ordinary plans: operation classification, portable manifests and safe compensation inversion for complete Replace plans.

## Why this matters

Cross-type reconciliation is common precisely at architectural boundaries where portability, approval and execution planning matter most. Leaving it as a planning-only primitive would make it second-class.

## Alignment

The added APIs preserve the same domain-neutral boundaries as same-type Sync.
