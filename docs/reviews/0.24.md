# 0.24 review — reversible state transitions

## Capability

Generated Deltas now expose `Invert()`. Complete Sync plans can be inverted into compensation plans with additions/removals swapped and updates reversed using the generated Delta inverter.

## Production value

Preview/revert flows, compensation, migration rollback and cancellation often need the exact inverse description of a previously calculated transition.

## Safety boundary

Upsert plans containing preserved current-only state are rejected as non-reversible because the missing desired-state information cannot be reconstructed safely.

## Alignment

Forge calculates the reverse plan but never claims the reverse operation is allowed or executes it.
