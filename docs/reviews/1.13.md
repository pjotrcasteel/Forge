# Forge 1.13 review — plan-to-plan Delta

## Capability

Forge can now compare two complete plan snapshots and independently classify added, removed, updated and unchanged operations and dependencies.

## Design

- Operations and dependencies keep their application CLR types and key types.
- `PlanElementDefinition<TItem, TKey, TDelta>` makes identity/equality/delta semantics consumer-owned and reusable.
- The implementation delegates reconciliation to the existing deterministic O(n) CrossSync engine.
- There is no JSON/string intermediate representation on the typed path.
