# 0.22 review — ordered streaming reconciliation

## Capability

`StreamingSync.PlanOrderedAsync` performs cross-type reconciliation over two key-ordered `IAsyncEnumerable<T>` sources using a merge-join. It yields additions, updates, removals, unchanged and preserved steps incrementally.

## Production value

Large database exports, catalogs, inventories and cloud-state snapshots should not require materializing both complete sides before reconciliation can begin.

## Safety

- cancellation is mandatory;
- both sources are validated as strictly ordered;
- duplicate or descending keys fail instead of producing an ambiguous plan;
- Replace and Upsert retain their existing semantics.

## Alignment

Forge still executes no I/O beyond consuming the asynchronous sequences supplied by the application.
