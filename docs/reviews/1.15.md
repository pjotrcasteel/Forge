# Forge 1.15 review — typed approval scopes

## Capability

Forge can partition operations into application-defined approval scopes and calculate the safe dependency order between those scopes.

## Security boundary

Forge does not know users, permissions, tokens, roles, or storage. It only calculates structural approval boundaries. Applications keep authorization and approval persistence in their security boundary.

## SOLID

Scope assignment is open for extension through `IApprovalScopeSelector<TOperation, TScope>`. Scope identity remains a consumer type.

## Complexity

Grouping and dependency collapse are O(V + E); scope waves reuse the deterministic dependency planner.
