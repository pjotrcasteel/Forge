# 0.27 review — plan composition and atomic pre-validation

## Capability

Portable plans can now be named and composed into a `ReconciliationBatch`. Component dependencies produce execution waves and cycles are surfaced before execution. Applications can run batch-wide validation rules against the entire proposed transition.

## Production value

Large changes are rarely one collection: service state, resources and relationships may each have independent plans but must be assessed together. The batch provides one pre-execution boundary without coupling Forge to transactions or orchestration engines.

## Alignment

Validation rules are application-supplied. Forge only aggregates structural facts, component dependencies and issues.
